Микросервисная платежная система (Payment Service + Notification Service)

Микросервис Payment Service – обрабатывает платежи, хранит транзакции.

Функциии:
Создание платежа (POST /payments)
Получение информации о платеже (GET /payments/{id})
Отмена платежа (POST /payments/{id}/cancel)
Отправка события в RabbitMQ при успешном платеже

Микросервис Notification Service – отправляет уведомления о платежах

Функциии:
Подписка на события платежей из RabbitMQ
Логирование уведомлений - в разработке
