# 🪙 Payment System (Payment Service)
Микросервисная платежная система(Платёжный сервис)
> [!WARNING]
> Проект ещё находится в активной разработке и не все представленные функции реализованы
## 🎀 О проекте
Payment Service - микросервис в системе платежей Payment System, который обрабатывает и хранит транзакции платежей. 
> [!WARNING]
> Сервис не работает с межбанковскими системами, перевод в другие банки имитируется функцией задержки и всегда помечается успешным. Принятие платежей из дргуих систем отсутствует.
## ⚙️ Стек технологий
- Golang, gRPC, RabitMQ, PostgreSQL, Redis
## 🛡️ Безопасность
- mTLS для шифрования трафика между всеми сервисами, включая соединения с базами данных
## 🧩 Что уже готово?
- Создание транзакции, получение информации о транзакции, отмена транзакции
- Отправка события в RabbitMQ при успешной транзакции
- Кеширование платежей в Redis для быстрого доступа к информации через GET
- Взаимодействие с Billing Service через gRPC
