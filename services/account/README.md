# 🪙 Transaction System (Billing Service)
Микросервисная платежная система(Биллинг сервис)
> [!WARNING]
> Проект ещё находится в активной разработке и не все представленные функции реализованы
## 🎀 О проекте
Billing Service - сервис в системе платежей Transaction System, взаимодействует с Transaction и SSO, работает со счетами пользователя(хранение, создание), создаёт операции для транзакций платежей, обрабатывает внутренние транзакции, валидирует токены, инициализирует систему ReBAC в SSO (оставляя сервис SSO независимым), настратвает доступ к методами из Transaction и SSO.
## ⚙️ Стек технологий
- Golang, gRPC, PostgreSQL, Redis
## 🛡️ Безопасность
- mTLS для шифрования трафика между всеми сервисами, включая соединения с базами данных
- JWT для валидации Access токенов
## 🧩 Что уже готово?
- Создание и пополенние счетов, внутренние/внешние переводы, конвертация валюты
- Хранение истории операций
- Валидация токенов
- Взаимодействе с сервисами SSO, Transaction и Client
- Инициализации ReBAC для Transaction System
- Настройка доступа с помощью ReBAC в сервсином слое
